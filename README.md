# Monrise Чайхона — приватный концепт
ID кандидата: C-005.
Статический сайт без зависимостей. Готовая production-версия: dist.
Из папки проекта: `node validate.mjs`; `python3 -m http.server 4315 --directory dist`.
BRIEF.md — факты, источники, ограничения. QA.md — проверка. Иллюстрация оригинальная, не фотография заведения. Перед официальным запуском согласовать информацию и материалы с владельцем.
